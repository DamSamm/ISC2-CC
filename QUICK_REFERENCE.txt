## 🚀 5-Minute Quick Start

### Step 1: Test Locally (Right Now!)
```
1. Open your file explorer
2. Navigate to: c:\Users\samue\Documents\isc2 CC
3. Double-click: index.html
4. Your quiz opens in your browser!
5. Click "Start Quiz" to test
```

### Step 2: Create GitHub Account
```
1. Visit https://github.com
2. Click "Sign up"
3. Complete signup (takes 2 minutes)
4. Verify your email
```

### Step 3: Create Repository
```
1. Click "+" icon → "New repository"
2. Name: isc2-cc-quiz
3. Select "Public"
4. Click "Create"
```

### Step 4: Upload Files
```
1. Click "Add file" → "Upload files"
2. Select these 3 files:
   - index.html
   - questions.json
   - README.md
3. Click "Commit changes"
```

### Step 5: Enable GitHub Pages
```
1. Go to "Settings" → "Pages"
2. Source: "Deploy from a branch"
3. Branch: "main"
4. Folder: "/ (root)"
5. Click "Save"
```

**DONE!** Your quiz is live at:
```
https://yourusername.github.io/isc2-cc-quiz/
```
